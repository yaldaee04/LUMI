# LUMI | لومی

A Persian RTL skincare e-commerce website built with HTML, CSS and JavaScript.

## About

LUMI is a responsive skincare store concept designed with a minimal and elegant interface. This project was built to practice front-end development, interactive UI, and e-commerce workflows.

## Features

- Responsive design
- Product listing and category filtering
- Dynamic shopping cart
- Quantity management
- Automatic price calculation
- Checkout form with validation
- Order summary
- Order confirmation page

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
